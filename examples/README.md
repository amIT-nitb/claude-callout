# Examples

Real-world recipes for `claude-callout`. Each recipe explains the goal, the commands, and what to expect.

- [Mute during a meeting](mute-during-meeting.md) — silence everything for a fixed window, auto-restore after.
- [Voice-only accessibility setup](voice-only-accessibility.md) — speak everything aloud, even when the terminal is focused.
- [Project-specific notifications only](project-specific-notify.md) — quiet at the user level, loud in one specific repo.

If you have a useful recipe to share, open an issue with the title `[example] <your-recipe-name>` and I'll add it.
